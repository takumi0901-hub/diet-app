# diet-app（体重記録アプリ）

![CI/CD](https://github.com/takumi0901-hub/diet-app/actions/workflows/ci-cd.yml/badge.svg)

ブラウザで動く、体重の記録アプリです。日付・体重・食事と運動のメモを記録し、一覧とグラフで確認できます。Google スプレッドシートと連携すると、PC とスマホで、同じ記録を使えます（連携は任意です）。

**公開ページ**: https://takumi0901-hub.github.io/diet-app/

## 主な機能

- 日付と体重、食事・運動のメモの記録（同じ日付は上書き）
- 記録の一覧表示と、削除
- 体重の推移を、折れ線グラフで表示
- 直近7日間の平均と、前日との差の表示
- Google スプレッドシートとの同期（任意）
- ネットワークにつながらないときも記録でき、送れなかった分は、あとで送り直す

## 使い方

### 1. 記録する

1. 公開ページを、ブラウザで開きます（グラフの表示には、インターネット接続が必要です）。
2. 「記録」画面で、日付と体重を入力して「保存」します。食事や運動のメモも、書けます。
3. 一覧とグラフに、反映されます。

連携を設定しなくても、記録は、お使いのブラウザの中（`localStorage`）に保存されます。

### 2. Google スプレッドシートと連携する（任意）

連携すると、別の端末でも、同じ記録を見られます。自分の Google アカウントで、次の準備が必要です。

1. Google スプレッドシートを新しく作ります。**共有はしません**（非公開のままにします）。
2. スプレッドシートの「拡張機能」→「Apps Script」を開き、このリポジトリの [`gas/Code.gs`](gas/Code.gs) の内容を貼って保存します。
3. Apps Script の「プロジェクトの設定」→「スクリプト プロパティ」で、`API_TOKEN` という名前で、**合言葉**を登録します。合言葉は、推測されにくい、32文字以上のランダムな英数字にします。
4. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」で、次のように設定して、デプロイします。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 表示された**ウェブアプリの URL**を、コピーします。
6. アプリの「設定」画面に、**連携 URL**と**合言葉**を入力して、「保存」します。
7. 「読み込み」ボタンで、スプレッドシートの内容が、画面に反映されます。

別の端末（スマホなど）でも、「設定」画面に、同じ連携 URL と合言葉を入力してください。設定は、端末ごと、ブラウザごとに必要です。

## データの保存と、プライバシー

- 記録は、まず**お使いのブラウザの `localStorage`** に保存されます。
- 連携を設定した場合は、**自分の Google スプレッドシート**にも保存されます。送れなかった記録や削除は「未同期」として残り、次の同期（保存・削除・「読み込み」・起動時）で、送り直します。
- **連携 URL と合言葉は、設定画面で入力した値を、そのブラウザの `localStorage` にだけ保存します。** このリポジトリや、公開ページには、含まれません。
- 連携 URL と合言葉は、**他人に教えたり、GitHub やチャットに書いたりしないでください**。漏れたときは、Apps Script の `API_TOKEN` を、新しい文字列に変更してください。
- このアプリの公開ページには、**誰のデータも、含まれていません**。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `app.js` | 画面の処理（入力、一覧、グラフ、設定、同期の表示） |
| `logic.js` | 計算の処理（直近7日間の平均、前日との差など）。画面に依存しない |
| `sheets.js` | スプレッドシート連携の API を呼ぶ関数 |
| `gas/Code.gs` | Google Apps Script のコード（スプレッドシートの窓口） |
| `tests/` | Jest による自動テスト |
| `.github/workflows/ci-cd.yml` | CI（ファイルと文法のチェック）と、GitHub Pages への自動公開 |

## 開発

```bash
npm ci      # ライブラリのインストール
npm test    # テストの実行
```

`main` ブランチにマージすると、GitHub Actions が、自動で GitHub Pages に公開します。変更するときは、作業用のブランチを作り、プルリクエストを出してください。

## 注意

このアプリは、体重などを記録するためのものです。目標の設定や、食事・運動の助言は、行いません。健康や体調について、気になることは、医師などの専門家に相談してください。
