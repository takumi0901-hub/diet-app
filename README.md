# diet-app

ブラウザで動く体重記録アプリです。日付・体重・食事と運動のメモを記録し、一覧とグラフで確認できます。

## 使い方

1. `index.html` をブラウザで開きます（グラフの表示には、インターネット接続が必要です）。
2. 「記録」画面で日付と体重を入力して「保存」します。同じ日付は上書きされます。
3. スプレッドシートと連携する場合は、「設定」画面で連携URLと合言葉を入力して「保存」します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `app.js` | 画面の処理（入力、一覧、グラフ、設定、同期の表示） |
| `logic.js` | 計算の処理（直近7日間の平均、前日との差など）。画面に依存しない |
| `sheets.js` | スプレッドシート連携の API を呼ぶ関数 |

## データの保存

- 記録は、まずブラウザの localStorage に保存します。
- 連携が設定されていれば、スプレッドシートにも送ります。送れなかった記録と削除は「未同期」として残し、次の同期（保存・削除・「読み込み」・起動時）で送り直します。
- 起動時と「読み込み」ボタンで、スプレッドシートから取得して画面を更新します。
- 連携URLと合言葉は、設定画面で入力した値を、そのブラウザの localStorage にだけ保存します。
